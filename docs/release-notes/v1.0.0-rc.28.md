# Weir v1.0.0-rc.28

Date: 2026-11-06

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release makes the Dashboard fully live: an update changes what is on screen in place, and nothing on it refreshes. It also stops Weir telling Deluno the same result twice.

## What Changed

- No new features in this release.

## Fixes And Stability

- **The Dashboard no longer refreshes itself.** Live updates now change cards, rows and tiles in place instead of rebuilding them, so nothing flashes or replays its arrival animation. (#1383)
  - The Today figure and the two-hour chart no longer blank out every five minutes.
  - A read that fails in the background, such as while Weir restarts, keeps the Dashboard on screen instead of replacing it with an error page.
  - Changing the workflow or the kind of work keeps the lists on screen until the new ones arrive.
  - Needs you no longer says "All clear" before it has looked.
  - Saving a workflow's folders no longer sends its Health check back to "Checking".
- **Nothing on the Dashboard moves by itself.** The "Live updates paused" and sign-out banners, and the notices in Needs you and Health, no longer push the page down. They sit over the edge of the page or panel instead. (#1383)
  - A card that changes station on a narrow screen glides to it instead of being redrawn.
  - Repeated Activity lines count up in place.
  - The Next and Working tiles keep their place when processing pauses, resumes or empties.
  - Connection timings, the chart's readout and the figures' units no longer nudge what is beside them as they change.

- **Deluno hears about each finished download once.** When Weir's regular check on Deluno came round at the moment Weir was reporting a finished download, the same report could go twice. Each finished download is now reported once.
- **Card titles with filters line up with Deluno.** Just finished's title keeps a minimum width, so its All / Movies / TV chips start in the same place as Deluno's.

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.28`, then `docker compose pull && docker compose up -d`.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0-rc.28`
