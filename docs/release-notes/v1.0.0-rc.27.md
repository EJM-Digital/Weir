# Weir v1.0.0-rc.27

Date: 2026-11-05

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release says speeds the same way everywhere, as Deluno does, and dates a finished file in Activity by when it finished.

## What Changed

- No new features in this release.

## Fixes And Stability

- **Speeds read the same way everywhere.** Under 1 MB/s a speed reads in whole KB/s ("120 KB/s"); from 1 MB/s it reads in MB/s, to a tenth under 10 ("3.4 MB/s") and whole from 10 ("42 MB/s"); from 1000 MB/s it reads in GB/s ("1.1 GB/s"). A disk's read and write each carry their own unit when they differ, and a chart counts in the unit of its largest value. This matches Deluno.
- **Activity dates a finished file by when it finished.** A file's "processed successfully" line in Activity carried the time its write began, so a long clean sorted behind things that happened while it ran. It now carries the time the clean finished. (#1376)

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.27`, then `docker compose pull && docker compose up -d`.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker
