# Weir v1.0.0-rc.21

Date: 2026-10-28

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release fixes four faults found while the tests were being extended to cover every line of Weir's code, and it ends with tests, not features. Nothing in it needs anything from you.

## Fixed

- **Signing out now ends the session even if you close the page at once.** Weir showed the sign-in page straight away, but the request that ends the session could still be unsent, or be cancelled when the page changed. Someone who signed out and then reloaded, reopened Weir or closed the tab could still be signed in. The request is now sent first and survives the page going away.
- **A call to a media manager is no longer lost on a connection the manager had already closed.** Weir kept connections to Sonarr, Radarr and Deluno open for up to a minute, and a manager or proxy that closes an idle connection sooner reset the next call, which failed with "could not reach". Weir now reuses a connection for 10 seconds at most.
- **A library clean whose file check gets an unreadable answer is refused with a reason.** A reply from the file check that was not valid JSON could stop the clean with an unexpected error. It is now refused like any other file Weir cannot make sense of.
- **Closing the log file can no longer clash with a page that is reading it.**

## Under The Hood

- **Tests.** Weir's server code and its command-line tooling are now measured to 100% of lines and branches, and the web app's lines to 100%. Code the tests proved could never run was removed instead of being excluded. Tests listen on the local machine only, so running them no longer raises a firewall prompt, and the browser tests keep more evidence when one fails.
- **Releases.** The release check keeps the mutation-testing proof of each area while that area is unchanged, and the recordings of Deluno and Weir now name the newest Deluno release (1.0.0-rc.30.35) and pull its image from the organisation's registry.
- **Dependencies.** Security fixes for packages used only to build and test (undici, zod, qs, and dompurify in the documentation site). None of them ships in Weir.

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.21`, then `docker compose pull && docker compose up -d`.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0-rc.21`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
