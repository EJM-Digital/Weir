# Weir v1.0.0-rc.25

Date: 2026-11-05

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release finishes a download that was already left waiting for ever before rc.24, and lines panel titles up with Deluno.

## What Changed

- No new features in this release.

## Fixes And Stability

- **A download left waiting from before is finished when Weir starts.** rc.24 stopped a download Deluno sends again from waiting for ever, but one already stuck that way stayed stuck. When Weir starts, it now looks again at any download that is still waiting with nothing being done for it, and says what it found. (#1365)
- **Panel titles sit where Deluno's do.** A panel's title now sits 12px below the panel's top edge, as in Deluno, so nothing shifts when you switch between them.

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.25`, then `docker compose pull && docker compose up -d`.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0-rc.25`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
