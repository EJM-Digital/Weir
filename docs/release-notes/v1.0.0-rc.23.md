# Weir v1.0.0-rc.23

Date: 2026-10-31

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release makes the Dashboard's timers and counts trustworthy: they keep to the clock, and they always agree with the cards on screen.

## What Changed

- No new features in this release.

## Fixes And Stability

- **Dashboard countdowns and timers keep to the clock.** They no longer skip a second or show the same second twice.
- **The counts always match the cards shown.** The Working count in the sidebar and the counts in the Pipeline now agree with the cards on the Dashboard, and the Queued count shows the true number of files waiting even when the queue is long.
- **The Windows tray icon shows the full Weir mark at every size.** The three-stream mark no longer loses detail at the small sizes Windows uses. (#1357)
- **Page headers match Deluno.** The small label above each page title, and the labels on the stat tiles, are now the same size and spacing as in Deluno. (#1359)
- **A finished hand-off no longer flickers back to working.** For a moment after Weir reported a hand-off back to the manager, its status could read as working again. (#1361)

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.23`, then `docker compose pull && docker compose up -d`.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0-rc.23`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
