# Weir v1.0.0-rc.24

Date: 2026-11-04

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release fixes a hand-off that could stay waiting for ever, and makes the Pipeline count the file it has just delivered.

## What Changed

- No new features in this release.

## Fixes And Stability

- **A download sent again after Weir finished it always gets an answer.** When Deluno sent the same download again after Weir had finished with it, and its folder was gone by then, Weir could keep saying the download was still waiting, until Deluno gave up. Weir now looks at it again and says what it found. (#1365)
- **The Delivering count includes the file just delivered.** While a delivered file shows its green Delivered card, the Delivering count above it reads 1, not 0. (#1351)

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.24`, then `docker compose pull && docker compose up -d`.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0-rc.24`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
