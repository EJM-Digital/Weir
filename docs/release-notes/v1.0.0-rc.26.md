# Weir v1.0.0-rc.26

Date: 2026-11-05

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/EJM-Digital/Weir/issues).

This release lines the Dashboard's rows up with Deluno's, so nothing moves when you switch between them.

## What Changed

- No new features in this release.

## Fixes And Stability

- **The Dashboard's rows match Deluno's.** The top band, the Pipeline and the row under it now take their heights from the window's height alone, by the same rule Deluno uses. The Dashboard no longer shifts by a few pixels when you switch between Weir and Deluno.

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data.
- Docker: change the image to `ghcr.io/ejm-digital/weir:1.0.0-rc.26`, then `docker compose pull && docker compose up -d`.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0-rc.26`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
