# Weir v1.0.0

Date: 2026-11-07

Weir's first stable release. It keeps the audio and subtitle tracks you want and drops the rest, for new downloads and for the library you already have, without re-encoding. Since 1.0.0-rc.28, the Dashboard updates fully in place and its filters look the same everywhere.

## What Changed

- **Just finished shows your latest finished titles, however long ago.** It no longer hides everything from before midnight once something finishes today. It shows your most recent finished titles, newest first.
- **One look for every filter.** Just finished's workflow filter uses the same switch as the rest of Weir, so every filter and choice looks alike.

## Fixes And Stability

- **A finished file's card stays in place as it becomes Delivered.** On the Pipeline, the card changes in place rather than being redrawn, so nothing flashes. (#1383)
- **Needs you keeps its place and only lists what needs you.** The list no longer redraws when it empties. A download that is only settling, which Weir is waiting on itself, is no longer shown as stuck. (#1383)
- **The sidebar and panel headers match Deluno exactly.** The workflow group label, the line under the app name and the panel links now use the same text sizes as Deluno, so nothing shifts when you switch between them.

## Upgrade Notes

- Windows: **Check now** then **Download update** then **Restart and apply** in System › About, or install `Weir-win-Setup.exe` over the top. Before installing, Weir saves a copy of its data. Installs from any 1.0.0 release candidate are offered this release.
- Windows shows a SmartScreen "Windows protected your PC" prompt the first time you run the installer, because Weir's installer is not code-signed. Choose **More info**, then **Run anyway**.
- Docker: set the image to `ghcr.io/ejm-digital/weir:1.0.0` or `ghcr.io/ejm-digital/weir:latest`, then `docker compose pull && docker compose up -d`. Your data volume is kept.
- Nothing else to do: no settings change and no one-time action is needed.

## Docker

- `ghcr.io/ejm-digital/weir:1.0.0`
- `ghcr.io/ejm-digital/weir:1.0` and `ghcr.io/ejm-digital/weir:latest`, both pointing to 1.0.0
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server. The arm64 image is tested under emulation, not yet on real arm64 hardware.
