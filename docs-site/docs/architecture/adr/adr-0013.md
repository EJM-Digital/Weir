# ADR-0013: A Media Manager Is a Kind, Not a Product Name

**Status:** Accepted

A media manager connection is a row with a `kind` field (Sonarr, Radarr, Deluno, or anything that posts Weir's own payload), not a set of routes and columns per product. Every inbound event arrives at one endpoint, `POST /api/v1/intake/webhook/{source}`, where the source only selects how the payload is read. Adding a manager means adding a dialect, not a route, job kind or module.
