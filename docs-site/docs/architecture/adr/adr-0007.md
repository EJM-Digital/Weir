# ADR-0007: Module-owned Worker Lanes (SQLite)

**Status:** Accepted; superseded in part by [ADR-0016](adr-0016)

When this was written, each module (Processing, Pruner, Subber) owned its own jobs table and in-process worker pool, and job kinds carried the owning module's prefix. Since ADR-0016 (#459) there is one jobs table (`jobs`) and one worker pool. Two parts survive: retired job-kind prefixes are still refused at enqueue and claim, and the admission rules that decide which job a worker may claim are unchanged.
