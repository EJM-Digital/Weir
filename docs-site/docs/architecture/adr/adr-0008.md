# ADR-0008: WeirSettings Aggregate for Runtime Configuration

**Status:** Superseded by [ADR-0017](adr-0017)

The Python backend held its runtime configuration in one `WeirSettings` aggregate, loaded once at process start. The .NET server keeps the idea under a different name: `WeirOptionsLoader` reads the `WEIR_*` environment once at startup into one immutable `WeirOptions` record. The server reads only the real environment, not `.env` files.
