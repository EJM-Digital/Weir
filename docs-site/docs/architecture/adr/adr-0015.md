# ADR-0015: Processing Asks a Port, and "No Answer" Is Not "Nothing"

**Status:** Accepted

Outbound, Weir asks every media manager that covers a library through one port: what it is importing now, and which library files it still keeps. Every answer is one of three values: reported, no signal, or unreachable. Only a report with nothing in it counts as safe to proceed, so a manager that could not be asked blocks a delete instead of clearing it. Any one of the managers covering a library can block.

The retention half of this ADR left Weir with Pruner; see [ADR-0016](adr-0016).
