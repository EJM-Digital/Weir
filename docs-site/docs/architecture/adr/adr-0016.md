# ADR-0016: Weir Is One Thing, and It Never Strands a File

**Status:** Accepted

Weir is a single-purpose processing stage. The module layer is gone, Processing is the application, and there is one jobs table and one worker pool. Retention (the former Pruner module) moved to Deluno, where the library and acquisition live (#473).

Every library has a failure policy, so a file Weir cannot process is never left stuck: pass it through unchanged (the default), hold it, or reject it and tell the manager why. A reject falls back to a pass-through when the manager cannot be told. Weir changes only what the operator configured, and every decision it makes is explained in plain language.

This ADR supersedes the module premise of [ADR-0007](adr-0007).
