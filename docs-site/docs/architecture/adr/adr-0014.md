# ADR-0014: A Processing Library Is a Row, Not One of Two Fixed Scopes

**Status:** Accepted

Processing is configured as any number of libraries instead of one fixed movie scope and one fixed TV scope. Each library is a row carrying its own paths, admission rules, schedule, capacity and media manager connections, and points at a named rule set that other libraries can share. Movies or TV is a property of the library that still selects the cleanup behaviour. Adding a library is a POST.

> **Naming.** Weir's Settings now call this row a **workflow**, because in Deluno, Radarr and Sonarr a "library" is where media ends up. The API, the database and this record keep the word "library".
